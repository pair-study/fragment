# PRD: 프래그먼트

## 1. 제품 개요

프래그먼트는 단일 조직의 인력 정보, 가능 시간, 최소 인원 조건을 기반으로 스케줄 초안을 추천하고, 사용자가 이를 조정·확정·보관할 수 있게 하는 근무 스케줄 관리 도구 MVP입니다.

MVP에서는 운영 웹이 전체 사용자 화면을 담당합니다. 따라서 회원가입, 로그인, 조직 생성, 운영 설정, 스케줄 추천, 확정 스케줄 조회까지 모두 반응형 웹에서 사용할 수 있어야 합니다.

## 2. 문제 정의

소규모 조직의 스케줄 편성은 보통 수기, 메신저, 스프레드시트에 의존합니다. 이 방식은 다음 문제가 있습니다.

- 인력별 가능 시간을 한눈에 비교하기 어렵습니다.
- 요일과 시간대별 필요한 최소 인원을 매번 수동으로 확인해야 합니다.
- 스케줄 초안을 만들 때 누가 어느 시간에 배정 가능한지 반복해서 대조해야 합니다.
- 확정된 스케줄 이력이 흩어져 있어 이전 스케줄을 다시 확인하거나 export하기 어렵습니다.

## 3. 목표

MVP의 목표는 사용자가 근무 스케줄 관리에 필요한 기본 정보를 입력하면, 시스템이 특정 근무 기간의 DRAFT 스케줄 초안을 생성하고, 사용자가 이를 조정한 뒤 CONFIRMED 스케줄로 확정할 수 있게 하는 것입니다.

### 사용자 목표

- 조직의 운영 시간과 휴무일을 설정할 수 있습니다.
- 인력 정보를 등록하고 관리할 수 있습니다.
- 인력별 가능 시간을 날짜와 시간 단위로 입력할 수 있습니다.
- 요일과 시간대별 최소 인원 조건을 등록할 수 있습니다.
- 입력된 조건을 기준으로 스케줄 초안을 추천받을 수 있습니다.
- 추천된 DRAFT 스케줄을 직접 추가·수정·삭제할 수 있습니다.
- 스케줄을 확정하고, 확정 이력을 보관함에서 조회할 수 있습니다.
- 확정 스케줄을 CSV로 export할 수 있습니다.

### 제품 목표

- 스케줄 초안 생성까지 필요한 입력 흐름을 단순화합니다.
- DRAFT와 CONFIRMED 상태를 분리해 추천 결과와 최종본을 명확히 구분합니다.
- 확정 스케줄을 보관함에서 다시 조회할 수 있게 해 서비스가 일회성 생성 도구에 머물지 않게 합니다.

## 4. 대상 사용자

### 근무 스케줄 관리 사용자

| 항목 | 내용 |
| --- | --- |
| 상황 | 여러 명의 인력을 날짜와 시간대별로 배정해야 함 |
| 현재 방식 | 메신저, 스프레드시트, 수기 메모를 조합해 스케줄을 편성 |
| 주요 문제 | 가능 시간과 최소 인원 조건을 반복 대조해야 해서 시간이 오래 걸림 |
| 기대 가치 | 조건을 입력하면 스케줄 초안을 빠르게 만들고, 필요한 부분만 직접 조정 |

## 5. MVP 범위

### 5.1 온보딩

- 회원가입
  - 이름
  - 이메일
  - 비밀번호
  - 비밀번호 확인
- 로그인
  - 이메일
  - 비밀번호
- 단일 조직 생성
  - 조직명
  - 매주 휴무일
  - 요일별 운영 시작 시간
  - 요일별 운영 종료 시간

### 5.2 조직 관리

- 조직 정보 조회
- 조직명 수정
- 매주 휴무일 수정
- 요일별 운영 시간 수정

### 5.3 인력 관리

- 인력 생성
- 인력 목록 조회
- 인력 수정
- 인력 삭제

인력 생성 시 사번은 시스템이 자동 생성합니다. 수정 화면에서는 사번을 읽기 전용으로 표시합니다.

### 5.4 가능 시간 관리

- 근무 시작 날짜와 근무 종료 날짜 선택
- 인력 선택
- 날짜별 가능 시간 선택
- 선택된 가능 시간 저장
- 기존 가능 시간 수정 및 삭제

가능 시간은 조직 운영 시간 기준 30분 단위 타임테이블로 입력합니다. 조직 휴무일에 해당하는 날짜는 선택할 수 없습니다.

### 5.5 최소 인원 조건

- 요일 선택
- 시작 시간 선택
- 종료 시간 선택
- 필요한 인원 수 입력
- 조건 생성, 수정, 삭제

최소 인원 조건은 스케줄 추천 시 시간대별 필요 인원을 판단하는 기준으로 사용합니다.

### 5.6 스케줄

- 추천 생성
- DRAFT 스케줄 달력 조회
- 미충족 조건 확인
- 날짜별 스케줄 추가
- 날짜별 스케줄 수정
- 날짜별 스케줄 삭제
- 스케줄 확정

스케줄 추천은 인력, 가능 시간, 최소 인원 조건, 근무 시작 날짜, 근무 종료 날짜를 기준으로 실행합니다. 추천 결과는 DRAFT 상태로 생성되며, 사용자가 직접 조정한 뒤 CONFIRMED 상태로 확정합니다.

### 5.7 보관함

- 확정 스케줄 이력 목록 조회
- 연도/월 기준 이력 필터링
- 선택한 이력의 읽기 모드 달력 조회
- CSV export

보관함의 스케줄은 CONFIRMED 상태의 최종본이며, 조회와 CSV export를 제공합니다.

### 5.8 대시보드

- 조직 정보 조회
- 확정 스케줄 달력 조회
- 확정 스케줄 CSV export
- 조직 수정 화면 이동

대시보드는 현재 조직 정보와 가장 최근 확정 스케줄을 빠르게 확인하는 첫 화면입니다.

## 6. 핵심 사용자 흐름

### 6.1 최초 진입

```txt
회원가입 또는 로그인
→ 조직 없음
→ 단일 조직 생성
→ 대시보드 진입
```

### 6.2 운영 설정 입력

```txt
인력 등록
→ 근무 기간 선택
→ 인력별 가능 시간 입력
→ 최소 인원 조건 입력
```

### 6.3 스케줄 생성 및 확정

```txt
스케줄 화면 진입
→ 추천 생성
→ DRAFT 스케줄 생성
→ 날짜별 스케줄 추가/수정/삭제
→ 미충족 조건 확인
→ 스케줄 확정
→ CONFIRMED 스케줄 생성
```

### 6.4 확정 스케줄 조회

```txt
보관함 진입
→ 연도/월 필터 선택
→ 확정 이력 선택
→ 읽기 모드 달력 조회
→ CSV export
```

## 7. 화면 범위

| 화면 | 경로 | 목적 |
| --- | --- | --- |
| 회원가입 | `/signup` | 계정 생성 |
| 로그인 | `/login` | 기존 계정 진입 |
| 조직 생성 | `/organization/new` | 단일 조직 생성 |
| 대시보드 | `/dashboard` | 조직 정보와 확정 스케줄 확인 |
| 조직 수정 | `/organization` | 조직 정보 수정 |
| 인력 관리 | `/workers` | 인력 기본 정보 관리 |
| 가능 시간 관리 | `/availability` | 인력별 가능 시간 입력 |
| 최소 인원 조건 | `/staffing-rules` | 시간대별 필요 인원 조건 관리 |
| 스케줄 | `/schedules` | 추천 생성, DRAFT 조정, 확정 |
| 보관함 | `/schedule-history` | 확정 스케줄 이력 조회/export |

## 8. 성공 기준

- 사용자는 조직 생성 후 운영 설정 화면으로 이동할 수 있습니다.
- 사용자는 인력, 가능 시간, 최소 인원 조건을 입력할 수 있습니다.
- 사용자는 추천 생성을 통해 DRAFT 스케줄을 만들 수 있습니다.
- 사용자는 날짜별로 DRAFT 스케줄을 추가·수정·삭제할 수 있습니다.
- 사용자는 DRAFT 스케줄을 CONFIRMED로 확정할 수 있습니다.
- 사용자는 보관함에서 확정 스케줄을 다시 조회할 수 있습니다.
- 사용자는 확정 스케줄을 CSV로 export할 수 있습니다.
